# Usmani Road Run 🛺

A Karachi side-scroller: get from **Maskan Chowrangi** to **Gulshan Bridge** along
Allama Shabbir Ahmed Usmani Road, past Disco Bakery, Coffee Wagera, the food
street, and straight through the khuddai.

Dodge rickshaws, qingqis, W-11 buses and dumper trucks. Mind the open manholes.
Survive the load shedding. Collect rupees. Chai makes you faster, bun kabab heals
you, biryani makes you invincible.

**Play:** open `index.html` in any browser: desktop (arrows + space) or
mobile (touch buttons).

Built with plain HTML5 canvas + JavaScript. No dependencies, no build step.
